# 05 — General substrate simulation

This folder contains reusable scripts for running diffusion-weighted simulations on a single substrate.

The goal is to move from validation tests to a more general workflow that can be reused with different substrate files. The substrate can be provided as either:

- an `.swc` file;
- a `.csv` file containing sphere positions and radii.

In both cases, the substrate is converted into an overlapping-sphere geometry using:

```julia
Spheres(..., overlapping = true)
```

This makes the scripts useful for testing many different substrates without rewriting the simulation code.

## Required input

Input substrate files should be placed in:

```text
substrate_generation/example_outputs/
```

For an SWC substrate, the expected format is:

```text
id type x y z radius parent
```

For a CSV substrate, the expected columns are:

```text
x,y,z,radius
```

Example files:

```text
substrate_generation/example_outputs/cylinder_soma_neurons_list_new.swc
substrate_generation/example_outputs/one_soma_list_new.swc
substrate_generation/example_outputs/one_soma_with_2_branches_list_new.swc
```

If a file is missing, copy it from the substrate generation output, for example:

```bash
cp ~/project/Grow_neurons/results/cylinder_soma_neurons_list_new.swc \
   substrate_generation/example_outputs/
```

## Utility file

### `utils_general_simulation.jl`

This file contains reusable helper functions used by the general simulation scripts.

It includes functions to:

- build relative paths to substrate files;
- load substrates from SWC or CSV;
- extract sphere positions and radii;
- create overlapping-sphere MCMR geometries;
- create bounding boxes around substrates;
- generate random spins;
- split spins into inside and outside compartments;
- create directional DWI sequences;
- run DWI simulations over several b-values;
- compute normalized signal `S(b)/S(0)`;
- compute log-normalized signal `ln(S/S0)`;
- estimate ADC using a simple log-linear fit;
- save detailed signal and ADC summary CSV files.

This avoids absolute paths such as:

```text
/home/valentine/project/...
```

and makes the scripts easier to reuse on another computer.

## Scripts

### `01_run_single_substrate_DWI.jl`

Runs a reusable diffusion-weighted simulation on a single substrate.

The script:

1. loads an SWC or CSV substrate;
2. converts it into an overlapping-sphere geometry;
3. creates random spins in a bounding box around the substrate;
4. optionally keeps only spins inside the substrate;
5. runs DWI simulations for selected b-values, echo times, and diffusion directions;
6. computes `ln(S/S0)`;
7. estimates ADC for each direction;
8. saves detailed signal and ADC summary CSV files.

Run with:

```bash
julia +1.11 --project=. docs/scripts/05_general_substrate_simulation/01_run_single_substrate_DWI.jl
```

Main user parameters are defined at the top of the script:

```julia
const SUBSTRATE_NAME = "cylinder_soma_neurons_list_new"
const SUBSTRATE_FORMAT = "swc"

const OUTPUT_PREFIX = "single_substrate_DWI"

const BVALS = [0.0, 0.5, 1.0]
const TE_VALUES = [40]
const TR = 150
const DIFFUSIVITY = 1.0
const NSPINS = 1_000
const N_REPEATS = 1
const BBOX_MARGIN = 2.0
const RANDOM_SEED = 1234
const MANUAL_TIMESTEP = 0.01
const USE_INSIDE_SPINS_ONLY = true
```

The substrate file is selected with:

```julia
const SUBSTRATE_NAME = "..."
const SUBSTRATE_FORMAT = "swc"  # or "csv"
```

The diffusion directions are selected with:

```julia
const DIFFUSION_DIRECTIONS = [
    ("x", [1.0, 0.0, 0.0]),
    ("y", [0.0, 1.0, 0.0]),
    ("z", [0.0, 0.0, 1.0]),
]
```

Outputs:

```text
docs/data/processed/single_substrate_DWI_signal.csv
docs/data/processed/single_substrate_DWI_ADC_summary.csv
```

The detailed signal CSV contains one row per b-value, TE, direction, and repeat.

The ADC summary CSV contains one row per TE, direction, and repeat.

## ADC model

The ADC estimate is based on the simple log-linear model:

```text
ln(S/S0) = c - ADC * b
```

where:

- `S` is the signal at a given b-value;
- `S0` is the signal at `b = 0`;
- `c` is the fitted intercept;
- `ADC` is the apparent diffusion coefficient.

A steeper negative slope in `ln(S/S0)` corresponds to a higher ADC.

## Example interpretation

For a long cylinder-like substrate aligned with the x-axis, the expected qualitative result is:

```text
ADC_x > ADC_y and ADC_x > ADC_z
```

This means that diffusion is less restricted along the long axis of the cylinder.

For a more isotropic or soma-dominated cell substrate, the ADC values may be similar across directions:

```text
ADC_x ≈ ADC_y ≈ ADC_z
```

This means that the substrate does not produce strong directional anisotropy under the tested parameters.

For example, when testing a cell with one branch and a large soma, the resulting curves can be very similar across x, y, and z. In that case, the script still validates that the workflow runs correctly, but the geometry itself does not show strong anisotropy.
